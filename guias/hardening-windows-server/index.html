Hardening de Windows Server

Os ajustes que mais reduzem risco num servidor Windows, em ordem de prioridade, com comandos PowerShell para verificar e corrigir.

Windows ServerPowerShellLAPSLinha de base

00Antes de começar

Júniornível
2 a 4 hpor servidor modelo
PowerShellcomo administrador
GPOpara escalar

Hardening é reduzir a superfície de ataque: menos serviços, menos contas com privilégio, protocolos antigos desligados e tudo registrado. Faça primeiro num servidor modelo e depois leve as configurações para GPO.

01Prioridades em ordem

#AçãoPor quê
1Atualizações mensaisA maioria dos ataques usa falhas já corrigidas
2Senha única por servidor com Windows LAPSEvita que a senha do administrador local abra todos os servidores
3Contas administrativas separadasO dia a dia não roda com privilégio
4Desligar SMBv1 e exigir assinatura SMBFecha caminhos clássicos de movimentação lateral
5RDP só com NLA e só a partir de servidores de saltoRDP exposto é porta de entrada de ransomware
6Firewall ligado nos três perfisBloqueia o que não foi explicitamente liberado
7Defender com EDR e regras de redução de superfície de ataqueDetecta e bloqueia comportamento malicioso
8Auditoria e envio de logs ao SIEMSem log não há investigação

02Verificar e corrigir com PowerShell

# SMBv1: verificar e remover (já vem desinstalado no Windows Server 2019 e posteriores)
Get-WindowsFeature FS-SMB1
Uninstall-WindowsFeature -Name FS-SMB1

# Exigir assinatura SMB no servidor
Set-SmbServerConfiguration -RequireSecuritySignature $true -Force

# Firewall ligado nos três perfis
Get-NetFirewallProfile | Select-Object Name, Enabled
Set-NetFirewallProfile -Profile Domain,Private,Public -Enabled True

# RDP com autenticação no nível da rede (NLA): 1 = ligado
(Get-CimInstance -Namespace root\cimv2\terminalservices -ClassName Win32_TSGeneralSetting -Filter "TerminalName='RDP-tcp'").UserAuthenticationRequired

# Windows LAPS: preparar o AD (uma vez) e ler a senha de um servidor
Update-LapsADSchema
Get-LapsADPassword -Identity SRV01 -AsPlainText

# Últimas atualizações instaladas
Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 5
Teste antes de exigir

Assinatura SMB e desligamento de protocolos antigos podem quebrar equipamentos legados, como impressoras e NAS antigos. Aplique primeiro num grupo piloto.
