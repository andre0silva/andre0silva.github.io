02DNS e horário

  • DNS integrado ao AD, com encaminhadores para resolução externa.
  • Em cada DC, o DNS primário aponta para outro DC e o secundário para o próprio servidor.
  • Estações e servidores usam só os DCs como DNS, nunca um DNS público direto.
  • O DC com a função de emulador PDC sincroniza com uma fonte externa; os demais seguem a hierarquia do domínio. Kerberos falha com diferença de relógio acima de 5 minutos.
# No DC emulador PDC: sincronizar com o NTP.br
w32tm /config /manualpeerlist:"a.ntp.br b.ntp.br" /syncfromflags:manual /reliable:yes /update
w32tm /query /status

03OUs e GPOs

Organize as OUs para facilitar delegação e aplicação de GPOs, não para espelhar o organograma. Um modelo comum:

EMPRESA
├── Admin        (contas e grupos administrativos, por camada)
├── Servidores   (por função: Arquivos, Aplicação, SQL)
├── Estacoes     (por site ou tipo)
├── Usuarios     (por site ou área)
├── Grupos
└── Servico      (contas de serviço)

Use redircmp e redirusr para que objetos novos não caiam nos contêineres padrão Computers e Users, onde não se aplicam GPOs de OU.

  • Administradores de domínio no grupo Protected Users.
  • Windows LAPS para a senha do administrador local.
  • Grupos Domain Admins e Enterprise Admins quase vazios e monitorados.

05Rotina de saúde e recuperação

netdom query fsmo

dcdiag /v /c /e /q

# Replicação: resumo e detalhes
repadmin /replsummary

# Ligar a lixeira do AD (uma vez, irreversível)
Enable-ADOptionalFeature -Identity 'Recycle Bin Feature' -Scope ForestOrConfigurationSet -Target 'ad.empresa.com.br'
Backup

Faça backup do estado do sistema de pelo menos dois DCs e teste a restauração em laboratório. Nunca restaure um DC a partir de snapshot de VM como forma de backup.
