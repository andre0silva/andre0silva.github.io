Servidor Linux seguro: primeiros passos

Os primeiros 30 minutos de qualquer servidor Linux novo, com os comandos para Ubuntu e para a família Red Hat.

LinuxUbuntuRHELSSHFirewall

00Antes de começar

Júniornível
30 minpor servidor
Ubuntu e RHELcomandos dos dois
SSH por chavesem senha
Não se tranque para fora

Antes de desligar o login por senha no SSH, abra uma segunda sessão e confirme que o login por chave funciona.

01Usuários, sudo e SSH

# No seu computador: gerar a chave e copiar para o servidor
ssh-keygen -t ed25519 -C "andre@notebook"
ssh-copy-id andre@10.1.20.15

# No servidor: usuário administrativo com sudo
sudo adduser andre                 # Ubuntu
sudo usermod -aG sudo andre        # Ubuntu (grupo sudo)
sudo usermod -aG wheel andre       # RHEL, Rocky, Alma (grupo wheel)

Depois, em /etc/ssh/sshd_config (ou num arquivo em /etc/ssh/sshd_config.d/):

PermitRootLogin no
PasswordAuthentication no
sudo sshd -t                     # valida a configuração antes de aplicar
sudo systemctl restart ssh       # Ubuntu (no RHEL o serviço se chama sshd)

03Firewall e serviços

# Ubuntu (ufw)
sudo ufw allow OpenSSH
sudo ufw enable
sudo ufw status verbose

# RHEL (firewalld)
sudo firewall-cmd --permanent --add-service=ssh
sudo firewall-cmd --reload
sudo firewall-cmd --list-all

# O que está rodando e escutando na rede
systemctl list-units --type=service --state=running
sudo ss -tulpn

Desative com sudo systemctl disable --now <serviço> o que não for necessário. Para bloquear tentativas repetidas de login no SSH, o fail2ban é uma opção simples.

05Logs e horário

  • Consulte logs com journalctl -u ssh (ou sshd) e journalctl -p err -b.
  • Envie os logs para o SIEM ou servidor central com rsyslog ou o agente da ferramenta.
  • Use chrony para sincronizar o horário; confira com chronyc tracking.
