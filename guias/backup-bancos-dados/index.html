Backup e restauração de bancos de dados

00Antes de começar

Snapshot de VM com banco em uso pode gerar cópia inconsistente. Banco crítico exige backup nativo ou com agente que coordene com o banco, e backup de log para atingir RPO de minutos.

01Estratégia por RPO

RPO exigidoEstratégia
24 hCompleto diário
4 hCompleto semanal + diferencial diário + log a cada 4 h
15 minCompleto semanal + diferencial diário + log a cada 15 min ou menos
Próximo de zeroReplicação (Always On, Data Guard, réplica de streaming) + backup de log

02SQL Server

  • Modelo de recuperação FULL nos bancos que precisam de restauração a ponto no tempo.
  • Completo + diferencial + log, com CHECKSUM e COMPRESSION; RESTORE VERIFYONLY após cada backup.
  • Em Always On AG, defina a réplica preferida para backup e garanta que o log não cresça sem controle.
  • DBCC CHECKDB periódico: backup de banco corrompido continua corrompido.
  • Backup dos bancos de sistema (master, msdb) e de logins, jobs e certificados de TDE.

03Oracle com RMAN

  • Banco em ARCHIVELOG; RMAN com backups incrementais nível 0 (semanal) e nível 1 (diário) e backup de archivelogs frequente.
  • Block change tracking ligado para incrementais rápidos.
  • Controlfile e SPFILE com autobackup; catálogo RMAN em banco separado.
  • RESTORE ... VALIDATE e CROSSCHECK regulares; política de retenção (RECOVERY WINDOW).
  • Data Guard para RPO baixo e failover; backup pode ser feito na standby.

04PostgreSQL

  • Backup físico com pg_basebackup ou ferramenta (pgBackRest, Barman) + arquivamento contínuo de WAL para restauração a ponto no tempo (PITR).
  • pg_dump para cópias lógicas de bancos específicos e migrações, não como única proteção de banco grande.
  • Verificação dos backups (pgbackrest verify ou equivalente) e monitoramento do atraso do arquivamento de WAL.

05Integração e segurança

  • Integração com a ferramenta corporativa (agente ou plugin) para catálogo, retenção e cópia imutável fora do servidor.
  • Criptografia dos backups e guarda das chaves (inclusive de TDE) fora do servidor do banco.
  • Conta de backup com privilégio mínimo; repositório inacessível a partir do servidor do banco para exclusão.
