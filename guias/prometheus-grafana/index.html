Prometheus e Grafana: métricas e dashboards

Uma stack de métricas pronta em Docker Compose, com as consultas PromQL que respondem às perguntas do dia a dia e uma regra de alerta de exemplo.

01Subir a stack com Docker Compose

compose.yaml:

services:
  prometheus:
    image: prom/prometheus
    ports: ["9090:9090"]
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
      - ./alertas.yml:/etc/prometheus/alertas.yml
  grafana:
    image: grafana/grafana
    ports: ["3000:3000"]

prometheus.yml:

global:
  scrape_interval: 15s

rule_files:
  - /etc/prometheus/alertas.yml

scrape_configs:
  - job_name: node
    static_configs:
      - targets: ["10.1.20.11:9100", "10.1.20.12:9100"]

Nos servidores, instale o node_exporter (pacote da distribuição ou binário oficial) e libere a porta 9100 só para o Prometheus. Em produção, fixe as versões das imagens e guarde os dados em volumes.

02Consultas PromQL do dia a dia

PerguntaConsulta
Uso de CPU por servidor (%)100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
Memória disponível (%)node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes * 100
Disco usado (%)100 - (node_filesystem_avail_bytes{fstype!~"tmpfs|overlay"} / node_filesystem_size_bytes{fstype!~"tmpfs|overlay"} * 100)
Alvos fora do arup == 0

03Regra de alerta

alertas.yml:

groups:
  - name: servidores
    rules:
      - alert: DiscoQuaseCheio
        expr: node_filesystem_avail_bytes{fstype!~"tmpfs|overlay"} / node_filesystem_size_bytes{fstype!~"tmpfs|overlay"} * 100 < 10
        for: 15m
        labels:
          severity: warning
        annotations:
          summary: "Menos de 10% livre em {{ $labels.instance }} ({{ $labels.mountpoint }})"

O for: 15m evita alertas por picos rápidos. O envio para e-mail, Teams ou Slack é feito pelo Alertmanager, apontado na seção alerting do prometheus.yml.

04Dashboards no Grafana

  1. Acessehttp://servidor:3000; troque a senha inicial do usuário admin.
  2. Adicione a fonte de dadosTipo Prometheus, URL http://prometheus:9090 (nome do serviço no Compose).
  3. Importe um dashboard prontoO dashboard "Node Exporter Full" (ID 1860 no site do Grafana) mostra tudo do node_exporter.
  4. Crie o seuUm painel por pergunta de negócio: disponibilidade, latência, erros, saturação.
