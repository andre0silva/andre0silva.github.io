Zabbix do zero: monitorando servidores

Do servidor instalado ao primeiro alerta no Teams ou Telegram, usando templates prontos em vez de configurar item por item.

01Instalação

  1. Escolha a versão LTSNa página de download do Zabbix, selecione a versão LTS mais recente, o sistema operacional, o banco e o servidor web: a página gera os comandos exatos.
  2. Instale server, frontend e bancoSiga os comandos gerados e conclua o assistente web do frontend.
  3. Troque a senha padrãoO usuário inicial é Admin; troque a senha e crie usuários nominais.
  4. Libere as portasTCP 10050 do server para os agentes (checagem passiva) e TCP 10051 dos agentes para o server (checagem ativa).

02Configurar o Zabbix agent 2

Em Linux, o arquivo fica em /etc/zabbix/zabbix_agent2.conf; no Windows, na pasta de instalação.

Server=10.1.10.50
ServerActive=10.1.10.50
Hostname=srv-web01
Hostname precisa bater

O valor de Hostname no agente deve ser idêntico ao nome do host cadastrado no frontend. Se não bater, as checagens ativas não chegam.

04Primeiro host monitorado

  1. Crie grupos de hostsPor função e ambiente: Servidores Linux, Servidores Windows, Rede.
  2. Cadastre o hostNome igual ao Hostname do agente, interface de agente com o IP e a porta 10050.
  3. Vincule o templateLinux by Zabbix agent ou Windows by Zabbix agent.
  4. Confira os dadosEm Monitoramento → Dados recentes, os itens devem começar a chegar em poucos minutos.
  5. Configure a notificaçãoAtive o tipo de mídia, associe ao seu usuário e crie uma ação para problemas de gravidade Alta ou maior.

05Erros comuns

  • Nome do host diferente do Hostname do agente.
  • Firewall bloqueando 10050 ou 10051.
  • Notificar todas as gravidades e treinar a equipe a ignorar alertas.
  • Banco sem manutenção: ajuste a retenção de histórico e tendências nos templates.
  • Monitorar só recursos (CPU, disco) e esquecer o serviço que o usuário usa (porta, página, transação).
