Logs centralizados com Elastic Stack

Coletar logs de Windows e Linux num só lugar, pesquisar em segundos e manter o custo de armazenamento sob controle.

ElasticsearchKibanaElastic AgentKQLLogs

00Antes de começar

Plenonível
Fleetgestão central de agentes

Hot → deleteciclo de vida

Sem logs centralizados, investigar um incidente significa entrar servidor por servidor. Centralizar também protege a evidência: um atacante que apaga logs locais não apaga os que já foram enviados.

01Arquitetura

ComponenteFunção
Elastic AgentColeta logs e métricas nos servidores
Fleet e Fleet ServerGerenciam os agentes e suas políticas a partir do Kibana
IntegraçõesPacotes prontos: System, Windows, Nginx, firewalls, Microsoft 365
ElasticsearchArmazena e indexa os dados
KibanaBusca, painéis, alertas e administração

Pode rodar no Elastic Cloud ou em servidores próprios. Alternativas com a mesma lógica: OpenSearch, Graylog, Grafana Loki e Wazuh (foco em segurança).

02Inscrever agentes

  1. Crie uma política de agenteNo Kibana, em Fleet, crie uma política por tipo de servidor (Windows, Linux web).
  2. Adicione integraçõesSystem para Linux, Windows para os logs de eventos, mais as dos serviços instalados.
  3. Copie o comando de inscriçãoO Kibana gera a URL do Fleet Server e um token de inscrição.
# Linux (dentro da pasta extraída do Elastic Agent)
sudo ./elastic-agent install --url=https://fleet.empresa.local:8220 --enrollment-token=<TOKEN>

# Windows (PowerShell como administrador)
.\elastic-agent.exe install --url=https://fleet.empresa.local:8220 --enrollment-token=<TOKEN>

04Ciclo de vida e dimensionamento

FaseUsoExemplo de prazo
HotDados recentes, consultas rápidas7 dias
Warm/ColdConsultas eventuais, hardware mais baratoaté 90 dias
Frozen ou snapshotArquivo pesquisável ou para auditoriaaté 1 ano
DeleteExclusão automáticaapós o prazo legal ou de auditoria

Conta rápida: 50 GB de logs por dia, mantidos 30 dias em hot, ocupam cerca de 1,5 TB; com uma réplica, perto de 3 TB. A política de ciclo de vida (ILM) move e apaga os dados sozinha.
